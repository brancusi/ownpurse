# The Brackenridge group, as xero-axi holds it

An invented group of four US-dollar companies, generated by xero-axi's fixture generator (its
`rust/tests/fixtures/demo/`). Every name, amount and id is made up; the record is safe to publish.

| alias | org | tenant id |
|---|---|---|
| `roast` | Tallowmere Coffee Roasting Co. | `c0ffee00-0000-4000-8000-0000000000a1` |
| `hold` | Brackenridge Lane Holdings Ltd | `b01d0000-0000-4000-8000-0000000000b2` |
| `design` | Quillfeather Design Consultancy LLP | `de519000-0000-4000-8000-0000000000c3` |
| `lab` | Saltmarsh Cupping Lab LLC | `1ab00000-0000-4000-8000-0000000000d4` |

- `record.sqlite`: the record, copied from xero-axi's `rust/tests/fixtures/demo/record.sqlite`. Organisations,
  accounts, bank transactions and manual journals, plus Xero's trial balances at 2024-12-31 and 2025-12-31.
- `gl.json`: the postings xero-axi derives from it (78 postings, debits equal credits), made with xero-axi
  `430c2897` (branch `gl-full-contract`):

  ```sh
  XERO_AXI_CONFIG=<a config whose store is this record> xero-axi --offline --json --full gl all --limit 1000000 > gl.json
  ```

ownpurse reads both: the record for books, accounts, parties and documents; `gl.json` for the postings, so the
rules that turn Xero documents into postings stay in xero-axi.
