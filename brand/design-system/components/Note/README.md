# Note

An annotation in the drafting manner: a capitalised key in lapis over a dashed rule, then plain text. Use Note for the explanation a careful bookkeeper would pencil beside a figure: why two books disagree, what a sync changed, what an agent assumed.

- `label` is one or two words: NOTE, ASSUMED, CHANGED, WHY.
- Keep it to two sentences. It is not an alert: errors and warnings say what went wrong in the place they happen.
- Agents write their reasoning into Notes; people can see what was assumed at a glance.
