# Sheet

Graph paper with a title block: the drafting board, used as an element for diagrams and explanations. The Sheet is a prop, not a background. Use it to frame a drawing, a diagram of how books connect, or a worked example.

- At most one Sheet per screen, and never as the page ground or behind running text longer than a caption.
- `titleBlock` names the drawing, like an architect's sheet: `{ sheet: 'A-002', subject: 'Card split', date: '2026-10-09' }`.
- Lines use `grid-major` and `grid-minor` only. Draw on it in `ink-1`, annotate in `lapis`, and mark the one thing that matters with the `coin`.
