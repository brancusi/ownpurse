# Tag

A small mono chip naming a source, a book or a state. - Neutral for sources and books: `xero`, `sheet`, `bank`, `household`, `roast`. Lowercase, as the CLI writes them.
- Tones echo Coin statuses when a row needs a label: `verdigris` agreed, `gilt` held, `coin` difference, `lapis` selected or linked.
- `dot` adds a small coin; use it for books in a multi-book view so each book reads at a glance.
- Never more than three tags on one row.
