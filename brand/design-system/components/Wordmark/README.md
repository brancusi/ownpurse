# Wordmark

The ownpurse name set in Bricolage Grotesque 800 with a coin for the o. The coin is cut to the letter's own size: it sits on the baseline and overshoots the x-height exactly as the o does. The component sets it as live type; the files in Logos are outlined and safe anywhere.

- Always lowercase, always one word: ownpurse. Never Ownpurse, OwnPurse or own purse, in the mark or in running text.
- `tone="color"`: the coin-o in `coin`, letters in `ink-1`. `tone="mono"`: one ink. `tone="reversed"`: letters in `ink-inverse` on `surface-inverse`.
- Minimum size 16px. Clear space: the coin's diameter on every side.
- `blink` turns the coin into a minus every six seconds. Use it on splash screens and the website header only.
- Never pair it with the Mark in a lockup; never stretch, outline, or set it in another face.
