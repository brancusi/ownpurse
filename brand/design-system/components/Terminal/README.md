# Terminal

The terminal frame: how ownpurse looks in a shell or the TUI, always on the dark terminal ground. ownpurse lives in the terminal first. Use this frame for docs, the website and screenshots of the CLI and TUI.

- The frame is always dark (`term-ground`), in both themes, because terminals are.
- Colour only what carries meaning: `coin` for negatives and differences, `ok` for agreed, `gilt` for held, `note` for selection and hints, `dim` for secondary text. Everything else is `term-ink`.
- Show real commands with real flags, and real output shapes: counts on every list, the next step as a hint.
