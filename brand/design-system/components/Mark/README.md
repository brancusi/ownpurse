# Mark

The ownpurse icon: a brow, a nose and two eyes, which is also a T-account with debit and credit either side. Use it where the name is already known or space is tight: app icon, favicon, the TUI frame, avatars for the agent. Use the Wordmark where the name must be read. **Never lock the Mark and the Wordmark together**; pick one per placement.

- `tone="color"` (default) on `surface-0` and `surface-1`; `tone="reversed"` on `surface-inverse` or `term-ground`; `tone="mono"` for one-ink printing, embossing, and anywhere the coin colour is already used nearby.
- Smallest size 16px tall. Clear space on every side: one eye's diameter (18 of the 96 grid units).
- `blink` belongs to living surfaces (TUI frame, splash, the agent's avatar while idle), never in documents or print.
- `state` gives the open eye a mood: `thinking` while the agent works, `minus` when a total is short, `plus` when it is over. Always say the same thing in words nearby.
- Don't recolour the brow or nose, rotate it, or put it inside a coin.
